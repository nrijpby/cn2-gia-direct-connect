## 先把 CN2 GIA三网直连说人话

CN2 是中国电信的下一代承载网，全称 China Next Generation Carrier Network。它又分两个档次：低一档的叫 CN2 GT，高一档的叫 CN2 GIA，全称 Global Internet Access。GIA 是 CN2 里的"头等舱"，路由节点通常全程走 59.43，少数省内没接入 GIA 的才会兜到 202.97，所以延迟更低、丢包更少、晚高峰更扛揍。

"三网直连"则是指机房同时接入了电信、联通、移动三家的线路，数据从国外机房直接拉回国内，不用绕道第三方国家。很多便宜 VPS 之所以白天还行、晚上崩盘，就是因为回程要绕日本、绕美国西海岸、绕欧洲一圈，三网直连就是把这个绕路问题从根上解决。

把这两个概念叠在一起，CN2 GIA三网直连的意思就清楚了：电信用户去程和回程都走 GIA 高端线路；联通、移动虽然去程各自走自己的直连优化线路，但回程统一被"拉回"到 CN2 GIA 上回国。这种"回程强制优化"的设计，让三大运营商的访问体验差距大幅缩小，不管你用的是哪家宽带，晚高峰该快还是快。
